## 2. Currently Risky or Brittle Behavior

1. The requested export content cannot be reconstructed from `session_turns`. Those rows are quota/resume summaries and omit content, native record shape, line number, byte offsets, and per-line hash. (`src-tauri/src/state/db.rs:559-572`, `/home/nes/projects/agent-harness/tmp/scratch/agent-runner-feature-requests/02-session-export.md:20-41`)
2. Batch-ingested turns usually lose transcript file provenance because `source_file` is persisted as an empty string. (`src-tauri/src/state/db.rs:2188-2201`)
3. Adapter scripts skip malformed native JSON lines and unreadable files, so a successful scan can hide transcript corruption that export would need to surface from the canonical source file. (`scripts/claude-code-turns:57-88`, `scripts/codex-turns:56-89`)
4. Locator errors are currently a mixture of absent config as `Ok(None)` and script/path failures as strings. Empty locator stdout and multi-line stdout are errors, not "not found." (`src-tauri/src/sessions/mod.rs:171-199`)
5. Locator execution creates `STATE_DIR` before running; the harness's export side-effect rule is stricter than the current locator helper. (`src-tauri/src/sessions/mod.rs:183-187`, `/home/nes/projects/agent-harness/tmp/scratch/agent-runner-feature-requests/02-session-export.md:54-64`)
6. The shared script runner's 600-second timeout was sized for first-run scans across large histories, but export's read path would inherit the same upper bound if it reused the helper as-is. (`src-tauri/src/sessions/mod.rs:27-30`, `src-tauri/src/sessions/mod.rs:241-252`)
7. Storage type and transcript locator are separate sources of truth. Provider config declares `SessionStorage`; sessions config declares executable scripts. A mismatch between them is currently possible and not durably recorded. (`src-tauri/src/config/providers.rs:81-109`, `src-tauri/src/config/sessions.rs:41-69`)
8. Storage vocabulary is already split between config serde (`codex`) and public locate metadata (`codex_session`). No backwards-compatibility shims are allowed by convention, so this is a naming risk rather than a compatibility surface to preserve. (`src-tauri/src/config/model.rs:195-200`, `/home/nes/projects/agent-runner/worktrees/06-locate/src-tauri/src/session_metadata/mod.rs:23-39`, `/home/nes/ai/conventions/no-backwards-compatibility.md:1-35`)
9. `resolve_resume` can collapse multiple historical candidates to one by recency, so export inherits resume's current ambiguity semantics rather than "any duplicate is ambiguous." (`src-tauri/src/state/db.rs:2713-2749`)
10. Resolver candidate selection ignores raw `session_turns` rows that lack chain/segment membership. Partially migrated or partially scanned state can contain turns that export cannot reach through ownership resolution. (`src-tauri/src/state/db.rs:2256-2271`, `src-tauri/src/state/db.rs:2696-2711`)
11. Multiple active segments in one chain are not treated as invalid state; the latest active row wins. Export would observe the same selected active provider/session as resume/locate. (`src-tauri/src/state/db.rs:2751-2764`)
12. Current `StateDb::open_default` is mutating: it creates parent directories, opens read-write, enables WAL, ensures schemas, and runs backfill. Export's requested no-side-effect behavior depends on the read-only open work sequenced before it. (`src-tauri/src/state/db.rs:431-615`, `/home/nes/projects/agent-runner/worktrees/06-locate/initiatives/06-session-override-contract.md:118-120`)
13. Locate in the stacked branch still calls `StateDb::open_default`; until the schema-probe/read-only-open work lands, the shared locate/export ownership path is not physically read-only. (`/home/nes/projects/agent-runner/worktrees/06-locate/src-tauri/src/main.rs:505-519`)
14. Trace currently treats missing located paths as `transcript_state = "missing"` and drops the returned path. That is enough for trace state but not enough for source preimage auditing. (`src-tauri/src/trace/mod.rs:334-380`)
15. Existing trace JSON is pretty-printed object output; no current stdout surface streams unbuffered JSONL records with "no partial transcript on error" semantics. (`src-tauri/src/main.rs:470-473`, `/home/nes/projects/agent-harness/tmp/scratch/agent-runner-feature-requests/02-session-export.md:58-64`)
16. `unsupported_record` is requested by export, but no current Rust module normalizes provider-native transcript records into canonical content or explicit unsupported entries. (`/home/nes/projects/agent-harness/tmp/scratch/agent-runner-feature-requests/02-session-export.md:58-63`, `src-tauri/src/lib.rs:1-11`)
17. Claude and Codex native line shapes differ materially. Claude's relevant fields are top-level `type`, `uuid`, `sessionId`, and content-like provider payloads; Codex uses `session_meta` and `response_item.payload`. Current ingestion adapters hide that difference by emitting only summaries. (`scripts/claude-code-turns:57-86`, `scripts/codex-turns:56-87`)
18. Compaction semantics are present in DB and migration, but there is no current export contract saying whether canonical output is full replay, post-compaction suffix, or compaction-boundary annotated replay. (`src-tauri/src/state/db.rs:2510-2536`, `src-tauri/src/migration/mod.rs:166-186`)
19. Migration's compaction boundary finder uses lossy UTF-8 text and `line.contains(turn_id)` over bytes. It is current precedent, but it is not a general source-offset or native-record parser. (`src-tauri/src/migration/mod.rs:162-186`)
20. Direct CLI sessions can be discovered through adapter scans, but those scans maintain mtime cursors and can skip unchanged files. Export must not refresh ingestion cursors, so current scan behavior is adjacent but not an export source of truth. (`scripts/claude-code-turns:9-15`, `scripts/codex-turns:12-14`, `/home/nes/projects/agent-harness/tmp/scratch/agent-runner-feature-requests/02-session-export.md:54-64`)
21. Config load behavior differs by path: trace treats malformed `sessions.toml` as an error, while resume paths use `unwrap_or_default` for providers/sessions config. Locate currently follows the resume-style defaulting for providers/sessions. (`src-tauri/src/main.rs:447-458`, `src-tauri/src/main.rs:1079-1084`, `/home/nes/projects/agent-runner/worktrees/06-locate/src-tauri/src/main.rs:530-538`)

## 5. Migration / Pre-Existing-State Implications

## 6. Observability Gaps That Exist Today

1. There is no CLI command that emits a canonical transcript by session id. Current public inspection is trace-by-invocation, resume-by-session with provider launch, and ad-hoc SQL. (`README.md:405-426`, `README.md:458-512`)
